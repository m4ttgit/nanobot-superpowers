# Equity Report Skill

Generate professional equity research reports for publicly traded companies.

## Usage

Trigger phrases:
- "equity report [company name]"
- "generate equity report for [company]"
- "stock analysis [company name]"

## Workflow

1. **Research** — Gather stock price, financials, business overview
2. **Generate** — Create a professional equity research report
3. **Save** — Save to `automatte:stocks/` in Google Drive
4. **Summarize** — Send an executive summary to the user

## Report Contents

- Company overview & stock data
- Financial performance
- Analyst consensus & price targets
- Bull/bear case investment thesis
- Risks & recommendations
- Sources & disclaimer

## Output Location

Reports are saved to: `automatte:stocks/[company_name]/[date]_equity_report.md`

## Examples

- "equity report Tesla"
- "stock analysis NVIDIA"
- "generate equity report for Apple"
