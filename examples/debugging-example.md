# Systematic Debugging Example

## Scenario

User reports: "The login button stopped working."

## How Nanobot Should Respond (with systematic-debugging skill active)

---

**Let's investigate this systematically before proposing any fixes.**

**Phase 1: Root Cause Investigation**

1. **Can you reproduce it?** What are the exact steps? (e.g., navigate to /login, enter credentials, click button — what happens?)
2. **Browser console errors?** Any red errors in the developer console when you click?
3. **Network tab?** Any failed requests when clicking the button?
4. **Did anything change recently?** Any deployments, config changes, or dependency updates in the last 24-48 hours?

Share what you find and I'll guide you through the next steps. We won't propose any fixes until we understand the root cause.
