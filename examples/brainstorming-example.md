# Brainstorming Example

## Scenario

User: "I want to add a feature that lets users export their data to PDF."

## How Nanobot Should Respond (with brainstorming skill active)

---

**Great idea! Let's explore this before we start building.**

A few quick questions to make sure I design this right:

1. **Purpose** — Is this for sharing reports with non-users, archiving, or something else?
2. **Format** — Should it be a single PDF, or multiple (one per report type)?
3. **Trigger** — Where should the export happen? Button in the UI? API endpoint? Both?
4. **Constraints** — Any fixed requirements? (e.g., must work offline, specific PDF library, max file size)

Take your time — no rush. We can start with just question 1 if that's easier.
