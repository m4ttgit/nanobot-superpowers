### 8. Working Capital Analyst Skill ✅ (NEW)
| # | Skill Name | Status |
|---|---|---|
| 75 | `nanobot-working-capital-analyst` | ✅ Done | Built from scratch |

**nanobot-working-capital-analyst:**
- SKILL.md — skill instructions for working capital analysis
- scripts/working_capital_calculator.py — calculates DS0, DP0, DIO, Cash Conversion Cycle
- references/working-capital-benchmarks.md — industry benchmarks, interpretation guide
- assets/sample_financials.json — example input with realistic values |

**What it calculates:**
- Working Capital = Cash + AR + Inventory - AP
- Working Capital Ratio = Current Assets / Current Liabilities
- Debtor Days (DS0) = (AR / Revenue) × 365
- Creditor Days (DP0) = (AP / COGS) × 365
- Inventory Days (DIO) = (Inventory / COGS) × 365
- Cash Conversion Cycle = DS0 + DIO - DP0
